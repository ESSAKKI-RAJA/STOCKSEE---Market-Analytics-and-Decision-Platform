# Support

Thank you for using STOCKSEE! If you need help with the platform, here are the best ways to get support.

## Community Support

For general questions, configuration help, and discussion, please use the following community resources:

1. **GitHub Discussions**: Visit our [Discussions Tab](https://github.com/STOCKSEE/discussions) to ask questions, share ideas, and interact with other users.
2. **Discord Community**: Join our official [Discord Server](https://discord.gg/stocksee) to chat with developers and contributors in real-time.

## Bug Reports and Feature Requests

If you believe you have found a bug in the code or have a specific feature request, please use the GitHub Issue Tracker.

- **[Report a Bug](../../issues/new?assignees=&labels=bug&template=bug_report.yml&title=%5BBUG%5D)**
- **[Request a Feature](../../issues/new?assignees=&labels=enhancement&template=feature_request.yml&title=%5BFEATURE%5D)**

Before submitting an issue, please ensure that you have searched through existing issues to avoid duplicates.

## Enterprise Support

For businesses and enterprise users requiring dedicated SLAs, priority bug fixes, or custom deployment architecture, we offer premium support packages.

Please contact **enterprise@stocksee.io** for more information.

## Security Issues

If you discover a security vulnerability, please do NOT open a public issue. Refer to our [Security Policy](SECURITY.md) and report it to **security@stocksee.io**.
